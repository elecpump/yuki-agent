# Yuki Agent 陪伴系统设计文档

> 日期：2026-08-10
> 状态：已确认（含两轮评审修正 v2/v3）
> 平台：Windows 10/11 · 语言：Python 为主

## 1. 目标与范围

设计一个常驻后台的**纯语音陪伴 agent**：在用户进行电脑娱乐活动（第一期聚焦**浏览网页 / 阅读 PDF/电子书**）时，感知屏幕内容与用户状态，提供**主动评论 + 被动回应**的双向陪伴。中文为主、中英混合。

**第一期范围**：浏览/阅读场景（浏览器网页 + 本地 PDF/电子书）。游戏、影音等多媒体场景列为后续扩展。

**明确的非目标**：
- 无虚拟形象 / 无 GUI 角色
- 不控制系统（不替用户操作浏览器、不点击）
- 不使用摄像头（视觉仅来自录屏 + 系统应用信息）

## 2. 总体架构：三进程分层 + 发布-订阅总线

```
                     ┌──────────── 本地消息总线（ZMQ PUB/SUB + REQ/REP，localhost）────────────┐
                     │                                                                          │
      采集层(独立进程)               认知层(独立进程)                    交互层(独立进程)
      ScreenCapture  ────帧流(按需)──► VisualUnderstander             WakeWordEngine ◄──音频主题
      AudioCapture   ────音频主题────► SpeechRecognizer(唤醒后才启)     HotkeyListener
      [AEC 回声消除]  ────事件流────► SensitiveFilter(第二道)           TTS Synthesizer
      [窗口级敏感检测]── 黑帧/暂停 ──► Personality Brain               FocusManager(打断)
      SystemMonitor   ─────────────► MemoryManager                   VolumeController(档位)
                                     L1 本地快答引擎                  ────audio/tts_ref─────┐
                                     Cloud LLM Bridge (L2)                                 │
                     ◄──────────── Supervisor 看门狗（独立重启任一层）───────────────────────┘
```

### 2.1 进程划分

| 层 | 进程 | 职责 | 特性 |
|---|---|---|---|
| 采集层 | Perception Agent | 截屏、音频采集、系统事件监控、窗口级敏感检测、AEC | 实时性优先，连续运行，可独立重启 |
| 认知层 | Cognition Agent | 视觉理解、语音识别、敏感过滤、人格内核、记忆管理、L1/L2 回应 | 重计算，处理云端 API |
| 交互层 | Interaction Agent | 唤醒词、热键、TTS 输出、打断控制、档位管理 | 低延迟输出 |

- 三进程相互独立，任一崩溃不影响其他层，由 Supervisor 看门狗自动重启
- 数据仅在本机流转；加密的**文本摘要**才发往云端

### 2.2 消息总线设计（关键修正 v2）

- **音频主题（PUB/SUB 多播）**：采集层持续发布音频帧（`audio/mic`）与 TTS 参考信号（`audio/tts_ref`，由交互层发布）；交互层订阅 `audio/mic` 做**唤醒词检测**（纯本地，不上传）；认知层订阅 `audio/mic`，但**仅在唤醒/热键触发后**启动 STT，避免无效推理。
- **事件主题**：感知事件（`event/*`）、唤醒事件（`event/awake`）。
- **REQ/REP**：认知层拉取屏幕帧、上层指令下发。

## 3. 组件职责

### 3.1 采集层

| 组件 | 职责 | 关键技术 |
|---|---|---|
| ScreenCapture | 按需截取前台窗口画面，**滚动停止后触发** | Windows 图形捕获（WGC/DXGI），降采样 |
| AudioCapture | 麦克风采集（含 AEC）；**第一期不含系统音频回路** | WASAPI；AEC 以 `audio/tts_ref` 为远端参考 |
| 窗口级敏感检测 | 黑名单类名/标题、安全桌面检测；命中即发**占位黑帧**并暂停视觉 | Win32 窗口枚举 |
| SystemMonitor | 前台应用/窗口标题/滚动/播放状态/输入 | Win32 UI Automation / WinRT |

**关键决策**：
- 事件驱动而非轮询：只在上游状态变化时发事件，控制认知层负载与成本
- **敏感源头阻断**（v2 修正）：采集层先做窗口级检测，命中即停止截屏并发送"占位黑帧"，从源头阻断明文跨进程传输；认知层敏感过滤作为第二道防线
- **AEC**（v2 修正）：交互层将 TTS 音频发布到 `audio/tts_ref` 主题，采集层订阅同步为远端参考信号，消除回声，支撑打断

### 3.2 认知层

| 组件 | 职责 |
|---|---|
| VisualUnderstander | 屏幕帧 + 前台 URL/标题 → 结构化"阅读情境"；带 **context cache** 复用 |
| SpeechRecognizer | 唤醒后语音 → 中文文本（中英混合） |
| SensitiveFilter | 第二道敏感过滤（VLM 产出文本进云端前） |
| L1 本地快答引擎 | 常驻 CPU 量化小模型/规则 + 记忆检索，**无网可用**，<1s 回应 |
| Personality Brain | 人格内核：决定是否主动开口、说什么、怎么回应 |
| MemoryManager | 三类记忆存取，衰减、强化、清除 |
| Cloud LLM Bridge | 情境摘要 → 云端多模态推理，返回 L2 深度回应 |

### 3.3 交互层

| 组件 | 职责 |
|---|---|
| WakeWordEngine | 本地唤醒词检测（持续监听，不发送音频），触发 `event/awake` |
| HotkeyListener | 全局热键（`Ctrl+Alt+Y` 呼叫、`Ctrl+Alt+M` 紧急静音），触发 `event/awake` |
| TTS Synthesizer | 中文中英混合语音合成；**流式**输出；同步发布 `audio/tts_ref` 供 AEC |
| FocusManager | 打断控制：TTS 播放时检测用户抢话 → 停止播放、进入倾听 |
| VolumeController | 安静 / 普通 / 活跃三档位切换 |

## 4. 核心数据流

### 4.1 主动评论闭环（阅读场景示例）

```
① 采集: SystemMonitor 发 FocusChanged{app,url,title}
         → 滚动事件(WM_MOUSEWHEEL/WM_VSCROLL/PageUp/Down) 重置静止计时器
         → 静止 300ms 后触发 ScreenCapture 截屏
         → 窗口级敏感检测通过 → 发送帧
② 认知: VisualUnderstander 以 (窗口标题+URL域+滚动位置%) 为缓存键
         → 未命中 cache 则 VLM 产出阅读情境 {主题, 正文, 阅读位置, 类型}
         → SensitiveFilter 第二道过滤
         → Personality Brain 决策: 档位/冷却/记忆检索 → 主动开口?
③ 交互: FocusManager 检查可打断性 → TTS 流式输出
```

### 4.2 被动回应闭环（用户主动说话）

```
唤醒词/热键 → 交互层发 event/awake（记录时间戳）
  → 认知层启动 STT，订阅 audio/mic
  → STT 文本 + 当前阅读情境 + 记忆 → Brain 决策
  → L1 本地快答(<1s) 或 L2 云端深度回应(2~5s, 流式TTS + "让我想想…"过渡)
```

### 4.3 分级响应机制（v2 修正）

| 级别 | 承载 | 延迟 | 触发 |
|---|---|---|---|
| L1 本地快答 | CPU 量化 SLM + 规则 + 记忆检索 | <1s | 简单确认、情绪共鸣、闲聊、断网兜底 |
| L2 云端深度 | 云端多模态 LLM | 2~5s | 复杂讨论、总结、联想；流式 TTS 降低等待感 |

- L1 引擎**常驻**认知层，CPU 量化推理，避免与 VLM 抢 GPU（v3 修正）
- 断网时 L1 升级为唯一回应引擎（配合本地人格兜底）；网络恢复后 L1 作快通道、L2 作深通道

### 4.4 时序要求

- 被动回应感知延迟目标 <1s（L1）；L2 允许 2~5s
- 主动开口冷却：安静 5min+ / 普通 ~2min / 活跃 ~30s
- 录音仅在唤醒后进入处理链；唤醒词检测本身全本地

## 5. 记忆系统

统一由 MemoryManager 管理，本地加密存储（SQLite + 向量库）。

### 5.1 三类记忆

| 类型 | 内容 | 存储 |
|---|---|---|
| 用户偏好与个人信息 | 显式（用户告知）+ 隐式（互动学习），带置信度与来源 | 结构化表 + 向量 |
| 对话历史 | 每次会话结构化摘要（主题/结论/情绪），保留最近 N 轮全文 | SQLite 会话表 + 向量 |
| 阅读/观看历史 | 主题摘要 + 关键观点 + 阅读进度 + 时间，支持跨内容关联 | 内容条目 + 向量 |

### 5.2 衰减与强化（v2/v3 修正）

- **衰减公式**：`decay = base * exp(-λ * days_since_last_access)`，检索排序时乘以系数，曲线可配置
- **last_access 初值**（v3 修正）：新建记忆初始化 `last_access = 创建时间`，首次被访问后切换为真实访问时间；未被访问的记忆随时间自然沉降，避免永远高权重
- 定期清理低于阈值的记忆；用户可手动"强化"某条记忆，重置其衰减

### 5.3 敏感与权限（v3 修正）

- 写入记忆时根据来源（VLM 文本命中敏感过滤 / 用户手动标记）设置 **sensitivity_level**
- 检索时 L1 本地与 L2 云桥**统一按 sensitivity_level 过滤**；高敏记忆**排除**出云端对话检索
- 云桥发送前校验日志，不记录原文

### 5.4 生命周期

写入（Brain 决策时）→ 读取（回应前检索 top-k 注入）→ 衰减/清理 → 用户可查看/清除任意记忆 → 一键全清

## 6. 人格与反馈闭环自进化

### 6.1 人格内核

- 人格设定（名字/性格/背景）为固定系统提示 + 记忆动态注入，共同构成 Brain 上下文
- **人格底线约束**：核心性格不漂移，可回滚

### 6.2 反馈来源

**显式反馈**：语音评价（"说得好""太吵了"）、档位切换、记忆纠偏
**隐式反馈**（从行为学习）：

| 用户行为 | 采集方式 | 推断信号 |
|---|---|---|
| 不理睬 | 音频静默 + 无回应 | 开口时机差 → 降温 |
| 打断 agent | FocusManager 检测抢话 | 说太多/太长 → 缩短篇幅 |
| 接话回应 | 用户开口接话 | 话题选对 → 加分 |
| 聊起来 | 对话轮数增加 | 话题值得延伸 |
| 反复翻页/跳过 | SystemMonitor | 内容没兴趣 → 少评价 |

### 6.3 三环递进学习（v2 修正）

- **环 1 · 参数自调（短期）**：隐式反馈实时微调冷却时间/篇幅/参与度，不持久化人格
- **环 2 · 偏好沉淀（中期）**：重复反馈模式 → 写入偏好记忆（带置信度），可被显式纠正
- **环 3 · 人格演化（长期）**：定期离线精修 Brain 人格提示（如月度），产出 **persona snapshot**（提示词 + 偏好参数 + 口语风格），版本号管理，可查看差异/一键回滚/导入导出

### 6.4 审计与重置

- 反馈信号、参数调整、快照版本全部记入可审计日志
- 支持查看"为什么这次开口了/没开口"
- 支持一键重置进化积累（回到初始人格快照）

## 7. 隐私与安全

**两层敏感拦截**：采集层窗口级阻断（源头）→ 认知层过滤（第二道）
**敏感内容处理**：密码框、银行、医疗记录、私人信息 → 占位黑帧 / 暂停感知 / 打码
**数据处理边界**：
- 唤醒词检测全本地，不发送音频
- 录音仅在唤醒后进入处理链
- 云端只接收裁剪后的文本摘要，不含原始帧/音频
- 反馈学习全部基于本地数据，不进云端
- 高敏记忆排除出云端检索

**用户控制**：
- 紧急静音热键 `Ctrl+Alt+M`（任何时候可用）
- 一键暂停/静音/清除记忆
- 锁屏/退出自动暂停全部感知

## 8. 错误处理与降级

### 8.1 分层容错
- 三进程独立 + Supervisor 看门狗自动重启
- 崩溃恢复：采集层重新订阅状态、认知层重载记忆、交互层恢复档位

### 8.2 云桥降级链（v2 修正）
```
云端不可用 → L2 关闭 → L1 本地快答 → 系统信息感知 → 断网本地人格兜底（不哑巴）
```
- **断网兜底**（v2 修正）：打包本地小参数模型（TinyLlama 类）或检索+模板引擎，断网时可继续"聊本地记住的内容"，并明确告知"现在连不上云端"

### 8.3 其他故障
- 感知歧义（无法识别内容）：标记未知，Brain 不强评，可问"你在看什么"
- 页面未加载/闪烁：冷却期内合并事件，抑制抖动
- 麦克风占用：暂停监听并提示；无输出设备：TTS 降级静默 + 屏幕提示
- 记忆损坏：重建索引，保留未损坏数据；记忆冲突：显式 > 隐式，新纠正 > 旧记忆

## 9. 测试与可观测性

### 9.1 分层测试

| 层 | 重点 | 方式 |
|---|---|---|
| 采集层 | 截屏准确性、滚动停止触发、前台识别、AEC | 集成测试（真实 Chrome/PDF 会话）+ mock 事件注入 |
| 认知层 | 敏感过滤、STT 中英、情境提取、记忆读写、L1/L2 分级 | 单测（固定帧/音频样本）+ 提示词评测集 |
| 交互层 | 唤醒误唤醒率、TTS、热键、打断 | 端到端脚本测试 |
| 全系统 | 完整闭环（阅读→评论→回应→记忆沉淀） | 仿真会话剧本 |

### 9.2 关键评测集
- **敏感屏蔽**：真实网页含密码框/银行/私人信息样本，验收误拦率 < 1%、漏拦率 < 0.1%
- **主动开口时机**：录制真实浏览会话，人工标注"该开口/不该开口"，回归档位决策
- **TTS 自然度**：中英混合长句主观评分

### 9.3 中间产物审计（v2/v3 修正）
- 审计日志**只记录过滤动作（时间、过滤规则编号、命中敏感类别），不存储原文**，避免日志成为新泄露点
- 唤醒测试日志只记录检测次数与置信度，**绝不保存音频片段**
- 验证敏感内容全程不出本地；唤醒词路径零上传；高敏记忆云端排除验证

### 9.4 删除验证
- 一键清除：SQLite + 向量索引物理抹除、无残留、不可恢复（含备份/临时文件）

### 9.5 可观测性
- 事件总线日志（时间戳 + 来源，可重放）
- 决策轨迹：每次开口记录 {触发情境, 档位, 冷却状态, 记忆命中}
- 结构化指标：误唤醒率、TTS 延迟、云 API 失败率、主动开口频率 vs 回应率
- 本地仪表盘（可选）：记忆、反馈信号、档位变化可视化

## 10. 未来扩展

- **游戏场景**：高帧率感知、低延迟反应、音频事件感知
- **影音场景**：恢复系统音频回路（以播放状态/媒体标题替代原始音频），多媒体内容感知
- **浏览器扩展辅助感知**（v3 修正）：本地浏览器扩展提供简化 DOM/文本摘要给 VisualUnderstander，辅助 VLM 提高准确率；仅本地通信，DOM 文本先过敏感过滤；避免传输敏感数据
- **摄像头表情感知**（需用户明确授权）
- **虚拟形象 / 文字窗口呈现**

## 11. 待定工程细节（Phase 2 详细设计时展开）

以下要点当前文档未展开，实际编码（尤其 Phase 2+）时必然遇到，进入详细设计阶段时需逐一明确：

### 11.1 进程间接口的正式定义
专设一份接口定义文档，至少包含：
- `audio/mic` 帧格式：采样率、位深、声道、帧长（建议基准：16kHz / 16bit / 单声道 / 20ms）
- `event/awake` 载荷：时间戳、唤醒源（wakeword/hotkey）、置信度
- `frame/request` REQ/REP 模式：请求帧的缓存键、超时约定（如 2s）与降级策略
- 错误码枚举：截屏失败、VLM 超时、STT 空结果等

### 11.2 VLM 与 L1 引擎模型选型
- 候选模型清单（VLM 本地量化版 vs 云端；L1 用哪个 SLM）
- 基准测试指标：VLM 截屏→情境 P50/P95 延迟；L1 STT 文本→输出文本延迟；二者常驻 CPU/内存占用
- 结果直接影响资源预算与延迟承诺，需写入第一期技术选型文档

### 11.3 上下文缓存一致性
- 现缓存键（窗口标题 + URL 域 + 滚动位置%）有盲区：同 URL 内容可随登录态/动态加载变化（如评论区展开）
- 未来版本引入内容指纹（如截屏感知哈希）：缓存命中但指纹不匹配时触发 VLM 重新读取，避免情境过时

### 11.4 TTS 流式与打断的时序协同
- 打断发生在句中被抢话时，TTS 缓冲区仍有未播音频，需在 FocusManager 明确策略：
  - 立即 flush 缓冲区并静音（响应快） vs 等当前音节结束后停止（更自然）
- 第一期建议：**立即停止 + 轻微淡出（20ms）**

### 11.5 第一期测试数据准备
- 评测集需要真实浏览/阅读数据，需提前启动收集
- 建议并行建立轻量级"浏览会话录制器"：录屏幕帧序列 + 窗口事件流（不含音频），用于评测集建设与离线回放测试决策逻辑

## 12. 关键决策记录（ADR 摘要）

| 决策 | 理由 |
|---|---|
